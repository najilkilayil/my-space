# My Space
Simple website that you can save notes in browser!

## Features
- Dynamic web designing
- Glassmorphism effect and theme
- User-friendly
- Modern UI design
- Secure with PIN
- Saved everything with localStorage
- Reset setup
- Remove option
- Edit and Copy option
- Points system
- Custom mouse icon
- Background animation

## Technical Side
This website is completely made up of HTML, CSS and JS.

User can create a PIN and only accessible to the website using that PIN only.

If the user is new or there is no saved notes the website will show up a *empty state* that enrage the user to use and make active in the website!

You can simply add the text needed to be saved in the website by entering in the input section and by clicking the sent button.

The notes will be showed as list menu with a default buttons of bottom-right corner of every list to remove or edit or copy the note.

Used glassmorphism theme for better UI design and also with background infinite moveing animation tiny-dots and endless count.

The website provides points system in-named keys (🗝️) which will help and encourage the users to unlock more features such as edit and copy buttons of list menu, the keys also stored in localStorage

Dynamic footer with input box and main heading and subheading with width changing animation effect according to focus of user needs.

Custom alert notification are on the website just designed using CSS and make functioning using JS

In this webiste provides custom mouse icon, icon of a emoji-🗝️ with perfect 90deg rotation.

### 🗝️s Calculation
The website calculates the keys(points)(🗝️) according to the equation,

Keys = Count of letters in the note / 4

That us , 1🗝️ per 4 letters!

To unlock editing feature need 150🗝️s and 100🗝️ss for copy feature.
